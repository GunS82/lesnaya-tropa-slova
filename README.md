# Лесная тропа знаний: слова и их значения

**Играть онлайн:** https://guns82.github.io/lesnaya-tropa-slova/

Отдельный урок для 2 класса. Ребёнок узнаёт значение слова, прямое и переносное значение, синонимы и антонимы. Антоним подбирается по всему сочетанию, а не по одному слову.

Материал опирается на страницы 41–57 учебника В. П. Канакиной и В. Г. Горецкого, «Русский язык», 2 класс, часть 1. Однокоренные слова со страницы 58 в этот выпуск не входят.

Тропа «Предложение» остаётся отдельной игрой: https://guns82.github.io/lesnaya-tropa-znaniy/

## Как открыть

```powershell
python -m http.server 8080
```

Затем откройте http://127.0.0.1:8080/

Проверка заданий:

```powershell
node js/check-logic.js
```

Прогресс этого урока хранится отдельно, ключ `forestWordMeaningProgress`.

## Что внутри

26 заданий на одной карте: значение слова, долина прямого и переносного смысла, поляна синонимов и мост антонимов.

Картинки лежат в `assets/scenes/<имя>.jpg`. Если файла нет, на карточке остаётся эмодзи. Подписи к картинкам пишет страница, не сам рисунок.
