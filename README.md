# Лесная тропа знаний: слова и их значения

**Играть онлайн:** https://guns82.github.io/lesnaya-tropa-slova/

Отдельный урок для 2 класса. Ребёнок узнаёт значение слова, прямое и переносное значение, синонимы и антонимы, затем корень, однокоренные слова, формы одного слова и окончание. Антоним подбирается по всему сочетанию. Одинаковые буквы ещё не делают слова родственными.

Материал опирается на страницы 41–64 учебника В. П. Канакиной и В. Г. Горецкого, «Русский язык», 2 класс, часть 1. Слог, ударение и перенос со страницы 65 в этот выпуск не входят.

Тропа «Предложение» остаётся отдельной игрой: https://guns82.github.io/lesnaya-tropa-znaniy/

## Как открыть

```powershell
python -m http.server 8080
```

Затем откройте http://127.0.0.1:8080/

Проверка заданий:

```powershell
node js/check-logic.js
```

Прогресс этого урока хранится отдельно, ключ `forestWordMeaningProgress`.

## Что внутри

42 задания на одной карте: значение слова, прямое и переносное значение, синонимы, антонимы, затем лес семейных слов, поляна корней, лабиринт похожих слов и мастерская окончаний.

Картинки лежат в `assets/scenes/<имя>.jpg`. Если файла нет, на карточке остаётся эмодзи. Подписи к картинкам пишет страница, не сам рисунок.
