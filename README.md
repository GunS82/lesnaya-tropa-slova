# Лесная тропа знаний: слова и их значения

**Играть онлайн:** https://guns82.github.io/lesnaya-tropa-slova/

Отдельный урок для 2 класса. Ребёнок узнаёт лексическое значение слова, общее название группы и разницу между однозначными и многозначными словами.

Материал опирается на страницы 41–49 учебника В. П. Канакиной и В. Г. Горецкого, «Русский язык», 2 класс, часть 1. Прямое и переносное значение в этот урок не входит.

Тропа «Предложение» остаётся отдельной игрой: https://guns82.github.io/lesnaya-tropa-znaniy/

## Как открыть

```powershell
python -m http.server 8080
```

Затем откройте http://127.0.0.1:8080/

Проверка заданий:

```powershell
node js/check-logic.js
```

Прогресс этого урока хранится отдельно, ключ `forestWordMeaningProgress`.

## Что внутри

12 заданий, своя карта и мостик между «Лесом слов» и «Долиной многих значений».

Новые типы: `sceneChoice` — выбрать одну картинку, `sceneMultiple` — отметить несколько и нажать «Готово». Картинки лежат в `assets/scenes/<имя>.jpg`. Если файла нет, на карточке остаётся эмодзи.
